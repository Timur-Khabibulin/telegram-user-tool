# База знаний проекта

Оглавление документации. Точка входа — `CLAUDE.md` в корне репозитория.

## Документы

| Документ | Назначение | Аудитория | Меняется | Когда читать |
|---|---|---|---|---|
| [agent-playbook.md](agent-playbook.md) | правила поведения агента | агент | редко | В начале любой задачи |
| [product.md](product.md) | описание проекта: что система делает | человек | редко | В начале любой задачи |
| [architecture.md](architecture.md) | архитектура кода репозитория | агент | при смене архитектуры | В начале любой задачи |
| [architecture-diagrams.md](architecture-diagrams.md) | архитектурные диаграммы: компоненты, топология, lifecycle, наблюдаемость | агент | при смене архитектуры | Если задача меняет архитектуру или нужна диаграмма компонентов/потоков |
| [db-schema.puml](db-schema.puml) | ER-диаграмма всех сущностей платформы по файлам SQLite | агент | при смене схемы БД | Если задача меняет схему таблиц или нужна визуальная ER-схема БД |
| [operation.md](operation.md) | эксплуатация: пути, systemd, деплой, логи | агент, оператор | при смене инфраструктуры | Если задача касается деплоя, systemd, путей на VPS или логов |
| [task-scheduling.md](task-scheduling.md) | дефолтное расписание задач по типу | агент, оператор | при смене дефолтов в коде | Если задача меняет расписание или дефолты запуска задач |
| [configuration.md](configuration.md) | конфигурация и секреты | агент, оператор | при смене конфигурации | Если задача трогает конфигурацию или секреты |
| [funnel-reports-access.md](funnel-reports-access.md) | чтение CSV-отчётов воронки с VPS по SSH | агент, оператор | редко | Если нужно прочитать CSV-отчёты воронки с VPS |
| [telegram-errors.md](telegram-errors.md) | каталог ошибок MTProto/GramJS и поведение системы при них | агент | при добавлении обработки новой ошибки | Если задача добавляет или меняет обработку ошибки MTProto/GramJS |
| [coding-standards.md](coding-standards.md) | стандарт кода TypeScript | агент | редко | Перед тем как писать или ревьюить код |
| [decisions/](decisions/) | архитектурные решения (ADR) | человек, агент | дополняется | Если нужно понять, почему решили именно так |
| [design/](design/) | аналитика фич (design doc) | человек | по версиям | Если задача касается конкретной существующей фичи — прочитать её design doc |

## Источники вне docs/

| Расположение | Назначение |
|---|---|
| `openspec/specs/` | нормативное поведение системы по способностям |
| `openspec/changes/`, `openspec/changes/archive/` | активные изменения и их история |
| `~/.openclaw/personas/<personName>/SOUL.md` (на сервере, вне репозитория) | персона runtime-агента (грузится в LLM как system-промпт), общий шаблон на несколько агентов — см. [operation.md](operation.md) |
