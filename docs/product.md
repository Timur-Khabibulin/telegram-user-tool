# Описание проекта

Платформа для запуска Telegram-агентов. Агент — это один Telegram-аккаунт, работающий
автономно по расписанию через MTProto, со ссылкой на персону (`SOUL.md`) из общего
шаблона. Платформа управляет несколькими агентами: данные у каждого свои, персона —
общий шаблон, на который может ссылаться несколько агентов; один агент назначен
админ-агентом и получает отчёты.

## Возможности агента

- **Мониторинг групп.** Читает непрочитанные сообщения, отвечает на релевантные в
  характере персоны, ведёт треды диалогов, оценивает авторов как кандидатов для DM.
- **Отправка DM.** Раз в день пишет отобранным кандидатам в личные сообщения.
- **Ведение DM-диалогов.** Продолжает переписку с сохранением контекста.
- **Прогрев аккаунта.** Имитирует активность обычного пользователя по расписанию.
- **Вступление в группы.** Обрабатывает очередь вступления в группы обсуждений.
- **Воронка.** Раз в день собирает метрики (активность в группах и DM, просмотры
  поста и подписчиков публичного канала, заявки на вступление в приватный канал) и
  отправляет отчёт.

## Персона

Поведение и стиль общения задаются файлом `SOUL.md` общего шаблона персоны
(`~/.openclaw/personas/<personName>/`); он загружается в LLM как system-промпт.
Агент ссылается на персону по имени (поле `persona` в `tg-account.json`) — правка
шаблона применяется ко всем агентам, ссылающимся на эту персону.

## Наблюдаемость

Результаты прогонов и дневная сводка отправляются в Saved Messages админ-аккаунта.
