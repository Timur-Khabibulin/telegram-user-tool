# Архитектурные решения (ADR)

Одно решение на файл: `NNNN-краткое-имя.md`. Файлы только дополняются; устаревшее
решение не переписывается, а помечается `Заменено` со ссылкой на новое.

## Шаблон

```markdown
# NNNN. Заголовок

- Статус: предложено | принято | заменено (→ NNNN)
- Дата: YYYY-MM-DD

## Контекст
Почему встал вопрос.

## Решение
Что решили.

## Последствия
Что из этого следует (плюсы и минусы).

## Отвергнутые варианты
Что ещё рассматривали и почему не выбрали.
```
