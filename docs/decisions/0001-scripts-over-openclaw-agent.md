# 0001. Скрипты вместо агента-исполнителя OpenClaw

- Статус: принято
- Дата: 2026-05-24

## Контекст
Изначально логика жила в `SKILL.md` на естественном языке: агент OpenClaw читал
инструкцию и сам вызывал инструменты через function calling. Это давало
недетерминированность (агент мог пропустить/переставить шаги), зависимость от
LLM на каждом служебном действии и сложную отладку.

## Решение
Перенести логику скиллов в код (`src/skills/*`) и запускать её standalone-
диспетчером (`src/scripts/dispatcher.ts`) по systemd-таймеру. OpenClaw-плагин
(`src/index.ts`) остаётся как тонкая обёртка над тем же ядром `core/` для
интерактивных вызовов.

## Последствия
- Детерминированный порядок шагов, простая отладка, дешевле прогоны (LLM зовётся
  только там, где нужна генерация).
- Поведение фиксируется в openspec, а не в естественном языке.
- Минус: логику теперь правят в коде, а не в тексте — выше порог входа.

## Отвергнутые варианты
- Оставить агента-исполнителя OpenClaw: отвергнуто из-за недетерминизма и стоимости.
- Полностью отказаться от OpenClaw: отвергнуто — плагин полезен для ручных вызовов.
