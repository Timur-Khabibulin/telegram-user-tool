## ADDED Requirements

### Requirement: CSV-отчёт отражает число приостановленных каналов

CSV-вложение ежедневного отчёта воронки SHALL содержать по каждому агенту число
каналов, у которых `status='suspend'` появился в отчётные сутки.

#### Scenario: Есть приостановленные каналы за день
- **WHEN** за отчётные сутки хотя бы одному каналу агента присвоен `status='suspend'`
- **THEN** в CSV-строке агента столбец числа приостановленных каналов отражает это количество

#### Scenario: Приостановленных каналов не было
- **WHEN** за отчётные сутки ни один канал агента не получил `status='suspend'`
- **THEN** столбец содержит 0
