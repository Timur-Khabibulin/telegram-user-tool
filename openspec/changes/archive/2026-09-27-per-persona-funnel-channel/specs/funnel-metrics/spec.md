## MODIFIED Requirements

### Requirement: Снапшот заявок в приватный канал

Система SHALL для каждого активного агента с настроенной персональной пригласительной
ссылкой (`private_invite_links`) снимать число неодобренных заявок на вступление в
приватный канал воронки **его персоны** по этой конкретной ссылке
(`messages.GetChatInviteImporters(peer=<канал персоны агента>, requested=true,
link=<ссылка агента>)`) от имени администратора приватных каналов (`REPORT_AGENT_ID`,
Модель A) и сохранять в `channel_snapshots.private_pending_requests` строки снапшота
этого агента. Целевой `peer` SHALL резолвиться как `funnelPrivateChannelId` из
`profile_data.json` персоны агента.

Если у персоны агента не задан `funnelPrivateChannelId`, подсчёт заявок для агентов этой
персоны SHALL пропускаться: значение SHALL быть NULL (не 0), MTProto-запрос для них не
выполняется. У агента без настроенной ссылки значение SHALL быть NULL (не 0), запрос для
него не выполняется. Итог заявок SHALL вычисляться **по персонам** — как сумма значений
по агентам в разрезе персоны, а не единым платформенным числом. При недоступности сбора
по конкретному каналу (нет прав, ошибка запроса) метрика заявок для агентов
соответствующей персоны SHALL быть пропущена с пометкой, прогон не падает.

#### Scenario: У агента настроена ссылка

- **WHEN** у агента есть запись в `private_invite_links`, у его персоны задан `funnelPrivateChannelId`, и `REPORT_AGENT_ID` имеет право `invite_users` в этом канале
- **THEN** число pending-заявок по ссылке этого агента в канале его персоны записывается в `private_pending_requests` его строки снапшота

#### Scenario: У персоны агента не задан приватный канал

- **WHEN** у персоны агента не задан `funnelPrivateChannelId`
- **THEN** `private_pending_requests` для агентов этой персоны — NULL, MTProto-запрос по ним не выполняется, прогон остальных персон продолжается

#### Scenario: У агента нет настроенной ссылки

- **WHEN** для агента нет записи в `private_invite_links`
- **THEN** `private_pending_requests` для него — NULL, MTProto-запрос по нему не выполняется

#### Scenario: Недостаточно прав

- **WHEN** `GetChatInviteImporters` для канала персоны возвращает `CHAT_ADMIN_REQUIRED`
- **THEN** заявки помечаются недоступными в отчёте для агентов этой персоны, остальные метрики и остальные персоны собираются как обычно

#### Scenario: Платформенный итог

- **WHEN** вычисляется итог заявок
- **THEN** он считается отдельно на каждую персону как сумма `private_pending_requests` её агентов (NULL трактуется как 0 в сумме), единого смешанного платформенного числа по всем персонам не выводится
