## ADDED Requirements

### Requirement: Приватный канал воронки задаётся в шаблоне персоны

Шаблон персоны `~/.openclaw/personas/<personName>/profile_data.json` SHALL поддерживать
опциональное поле `funnelPrivateChannelId` — id приватного канала воронки этой персоны
в формате marked peer id (вид `-100…`, как в `get_dialogs`/`tg-channels.db`). Это поле
SHALL быть единственным источником истины о приватном канале воронки персоны; общая
константа приватного канала SHALL не использоваться. Поле SHALL быть опциональным: его
отсутствие SHALL не приводить к ошибке загрузки шаблона.

Система SHALL предоставлять лёгкое чтение `funnelPrivateChannelId` персоны, не требующее
наличия канальных файлов шаблона (фото/пост), — резолвинг канала для сбора воронки SHALL
не падать из-за неполного шаблона персоны.

#### Scenario: Поле задано

- **WHEN** `profile_data.json` персоны `irina` содержит `"funnelPrivateChannelId": "-1003698044714"`
- **THEN** резолвинг приватного канала воронки для агентов персоны `irina` возвращает `-1003698044714`

#### Scenario: Поле отсутствует

- **WHEN** `profile_data.json` персоны не содержит `funnelPrivateChannelId`
- **THEN** загрузка шаблона персоны не падает, а резолвинг приватного канала воронки для этой персоны возвращает «канал не задан»

#### Scenario: Чтение id канала не требует канальных файлов

- **WHEN** нужно получить `funnelPrivateChannelId` персоны, в папке которой нет `post.txt`/`channel_photo.*`
- **THEN** id канала читается напрямую из `profile_data.json` без обращения к канальным файлам и без ошибки об их отсутствии
