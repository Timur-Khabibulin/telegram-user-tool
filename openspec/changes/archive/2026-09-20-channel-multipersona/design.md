## Design

Полное техническое решение — в
[docs/design/channel-multipersona/architecture.md](../../../docs/design/channel-multipersona/architecture.md)
(DDL двух таблиц, отображение функций `core/db/discovery.ts`, резолвинг персоны,
план миграции, границы депрекейта). Здесь — только ключевые решения change-уровня,
на которые опираются дельты спек и задачи; детали не дублируются.

### Двухтабличная модель реестра

`discovery.db` вместо одной `discovered_channels` содержит:
- `channels(canonical_link PK, added_at, метрики…)` — реестр канала; «один факт —
  один дом» для метрик; база под R9.
- `channel_assignments(persona, canonical_link, agent_id NULLABLE, assigned_at,
  PRIMARY KEY(persona, canonical_link))` — закрепление в разрезе персоны;
  PK держит инвариант R1.

Два прежде смешанных смысла `NULL` разведены: старый «нераспределённый NULL-пул»
исчезает вместе с пул-механикой; новый `agent_id IS NULL` = пустой агентский слот
(персона за каналом есть, активного агента нет — после бана до ротации).

### Персона как единица таргетинга

Агент принадлежит ровно одной персоне (поле `AccountConfig.persona`), поэтому
разрез по персоне обеспечивается сужением **множества** целевых агентов, а не
фильтром на уровне каждого канала. `resolvePersonaTargets(persona)` возвращает
активных агентов персоны; пустой результат → отказ прогона (R12). `parseAgentSpec`
удаляется; три входа распределения (бот, redistribute, `distribute-channels`)
сходятся на `runDistribution(rows, persona, …)`.

### Пустой слот пишет только ротация

`agent_id` меняет единственный автоматический путь — `channel-rotation`
(заполнил цель / не нашёл → `NULL`), а не путь выхода из канала — ради «один
факт — один дом». Окно «бан → ротация» безопасно: строка уже принадлежит персоне,
забаненный агент неактивен и целью не станет.

### Депрекейт — только штамп

Полный выпил пул-механики и similar-дискавери — отдельная под-задача. В этом change
им проставляется депрекейт-комментарий с датой последнего изменения; после смены
схемы запускать их нельзя (пишут по старой модели).
