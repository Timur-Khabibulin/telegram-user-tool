## ADDED Requirements

### Requirement: Колонка персоны в CSV-вложении отчёта

CSV-вложение отчёта-воронки (`buildFunnelCsv`) SHALL включать колонку «персона» для
каждой строки-агента со значением персоны агента из его конфига
(`AccountConfig.persona`). Колонка «пул» из отчёта убирается.

#### Scenario: Строка агента содержит персону

- **WHEN** формируется CSV-вложение отчёта-воронки
- **THEN** в строке агента колонка «персона» содержит значение `persona` из конфига
  этого агента, а колонки «пул» в отчёте нет

## REMOVED Requirements

### Requirement: Колонка пула в CSV-вложении отчёта

**Reason:** Сущность «пул» (`agent_pools`) заменяется персоной как актуальной
единицей группировки агентов; колонка «пул» в отчёте больше не выводится.

**Migration:** Значение берётся из `AccountConfig.persona`, а не из `agent_pools`.
