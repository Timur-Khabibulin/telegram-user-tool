## MODIFIED Requirements

### Requirement: Оператор получает CSV-отчёт по каналам в Saved Messages

Система SHALL по запросу оператора собирать каналы всех агентов с кэшированным средним
охватом (`avg_views`), формировать CSV-файл и отправлять его в Saved Messages
`REPORT_AGENT_ID` — не обязательно совпадающего с агентом, чьи данные (кэш `avg_views`)
использованы для отчёта.

#### Scenario: CSV отправлен получателю отчётов

- **WHEN** оператор запрашивает отчёт по охвату каналов
- **THEN** CSV-файл со всеми каналами (отсортированными по убыванию охвата, каналы без охвата — в конце) отправляется в Saved Messages `REPORT_AGENT_ID`
