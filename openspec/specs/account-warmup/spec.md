# account-warmup Specification

## Purpose

Периодическое «прогревание» аккаунта — фоновое чтение непрочитанных чатов и
разметка их прочитанными без ответов, чтобы аккаунт выглядел активным.

## Requirements

### Requirement: Agent reads unread chats and marks them as read

Скилл `account-warmup` SHALL выполнять следующую последовательность за один прогон:
1. Получить список чатов с непрочитанными сообщениями через `telegram_get_dialogs`
2. Случайно перемешать список и взять не более 15 первых
3. Для каждого чата: получить сообщения через `telegram_get_messages`, затем немедленно пометить как прочитанные через `telegram_mark_as_read`
4. Между обработкой чатов делать паузу 10–30 секунд

#### Scenario: Список непрочитанных не пуст

- **WHEN** `telegram_get_dialogs` возвращает N > 0 чатов с unread
- **THEN** агент обрабатывает min(N, 15) случайных чатов, вызывая `get_messages` и `mark_as_read` для каждого

#### Scenario: Список непрочитанных пуст

- **WHEN** `telegram_get_dialogs` возвращает пустой список
- **THEN** агент завершает прогон без ошибок

#### Scenario: Лимит 15 каналов за прогон

- **WHEN** `telegram_get_dialogs` возвращает более 15 чатов
- **THEN** агент обрабатывает ровно 15 случайно выбранных, остальные пропускает

#### Scenario: FLOOD_WAIT при обработке чата

- **WHEN** любой инструмент возвращает ошибку `FLOOD_WAIT_X`
- **THEN** агент ждёт X секунд, повторяет вызов один раз; если ошибка повторяется — завершает весь прогон

#### Scenario: Ошибка отдельного чата

- **WHEN** `telegram_get_messages` или `telegram_mark_as_read` возвращает ошибку (не FLOOD_WAIT)
- **THEN** агент пропускает этот чат и переходит к следующему
