## Requirements
### Requirement: Персона агента задаётся ссылкой в `tg-account.json`
`tg-account.json` агента SHALL содержать обязательное поле `persona` —
имя папки шаблона персоны в `~/.openclaw/personas/`. Поле проверяется при
загрузке конфигурации аккаунта наравне с `apiId`/`apiHash`/`sessionString`.

#### Scenario: Персона указана
- **WHEN** `tg-account.json` агента содержит `"persona": "maria"`
- **THEN** конфигурация аккаунта загружается успешно, `persona` доступна
  вызывающей стороне как `"maria"`

#### Scenario: Персона не указана
- **WHEN** `tg-account.json` агента не содержит поле `persona`
- **THEN** загрузка конфигурации аккаунта завершается ошибкой с
  человекочитаемым сообщением об отсутствующем обязательном поле, как для
  `apiId`/`apiHash`/`sessionString`

### Requirement: Общий каталог шаблонов персон
Шаблоны персон SHALL храниться в общем каталоге `~/.openclaw/personas/
<personName>/`, не привязанном к какой-либо конкретной фиче создания
агента. Имя папки — уникальный идентификатор персоны; отдельное поле
`id`/`name` внутри папки не используется.

#### Scenario: Разрешение пути к персоне
- **WHEN** нужно найти шаблон персоны с именем `maria`
- **THEN** используется путь `~/.openclaw/personas/maria/`

### Requirement: Текст промпта читается из шаблона на каждый прогон
`SOUL.md` персоны SHALL читаться напрямую из `~/.openclaw/personas/
<personName>/SOUL.md` на каждый прогон диспетчера агента — без копирования
в рабочую папку агента (`workspace-<agentId>/`) и без кэширования между
процессами.

#### Scenario: Правка персоны применяется без действий с агентом
- **WHEN** содержимое `~/.openclaw/personas/maria/SOUL.md` изменено
- **THEN** следующий прогон любого агента с `"persona": "maria"` использует
  уже новый текст, без каких-либо дополнительных действий над агентом

### Requirement: Отсутствие персоны — фатальная ошибка прогона
Если у агента не задано поле `persona`, либо файл `~/.openclaw/personas/
<personName>/SOUL.md` не найден на диске — SHALL прогон диспетчера для
этого агента завершаться с ошибкой (ненулевой код выхода процесса), а не
продолжаться с пустым текстом персоны.

#### Scenario: Файл шаблона отсутствует
- **WHEN** `tg-account.json` агента указывает `"persona": "unknown"`, а
  каталог `~/.openclaw/personas/unknown/` не существует
- **THEN** прогон диспетчера для этого агента завершается ошибкой,
  ни одна задача из расписания за этот прогон не выполняется

### Requirement: Остальные файлы шаблона копируются один раз при регистрации
Файлы шаблона персоны, не являющиеся текстом промпта (`post.txt`,
`photo_profile_N.*`, `channel_photo.*`, `channel_post_photo.*`,
`default_agent_data.json`, `profile_data.json`) SHALL продолжать
копироваться в процесс регистрации агента один раз — как одноразовая
настройка TG-профиля аккаунта, не как источник, читаемый рантаймом
повторно.

#### Scenario: Регистрация нового агента
- **WHEN** создаётся новый агент со ссылкой на персону `maria`
- **THEN** фото профиля, пост и текстовые данные профиля из
  `~/.openclaw/personas/maria/` копируются в процесс настройки аккаунта
  один раз; `SOUL.md` не копируется — только ссылка `persona` сохраняется
  в `tg-account.json` агента
