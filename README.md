# Telegram Agent Platform

Платформа для запуска Telegram-агентов. Агент — это один Telegram-аккаунт со своей
персоной, работающий от своего имени через MTProto: читает непрочитанные сообщения,
отвечает в характере персоны, копит и обрабатывает DM-кандидатов, прогревает аккаунт
и собирает воронку. Платформа управляет несколькими агентами — данные и персона
у каждого свои.

## Как устроено

Система работает в двух режимах поверх общего ядра `src/core/`:

- **OpenClaw-плагин** (`index.ts`) — интерактивные инструменты для ручного вызова.
- **Standalone-диспетчер** (`src/scripts/dispatcher.ts`) — запускается systemd-таймером
  по расписанию, исполняет назревшие задачи (скиллы) как код.

## Стек

- **TypeScript**, исполнение через `tsx`
- **MTProto**: GramJS (`telegram`) и mtcute (`@mtcute/*`, в т.ч. конвертация tdata-сессий)
- **SQLite** (`better-sqlite3`) — персистентность, у каждого агента своя БД
- **LLM**: ai-sdk; primary — OpenAI через codex-подписку, fallback — DeepSeek
- **Планирование**: systemd-таймеры + `cron-parser`
- **Прочее**: `zod` / `typebox` (валидация), `cheerio` (веб-превью каналов)

## Структура репозитория

| Путь | Назначение |
|---|---|
| `src/core/` | общее ядро: БД, конфиг, MTProto-клиент, планировщик, lifecycle |
| `src/features/` | фичи платформы (авто-замена банов, резерв аккаунтов и др.) |
| `src/skills/` | скиллы — единицы работы диспетчера |
| `src/llm/` | слой доступа к LLM |
| `src/scripts/` | диспетчер и операторские скрипты |
| `index.ts` | точка входа OpenClaw-плагина |
| `skills/` | `SKILL.md` — декларации скиллов |
| `deploy/systemd/` | шаблоны systemd-юнитов |
| `docs/` | база знаний (точка входа — `docs/README.md`) |
| `openspec/` | нормативные спеки способностей и история изменений |

## Документация

Полная база знаний — в [`docs/`](docs/README.md): архитектура, эксплуатация,
конфигурация, решения (ADR), design-доки фич. Точка входа для разработчика — `CLAUDE.md`.

## Конфигурация и данные

Секреты, конфигурация рантайма (`openclaw.json`), шаблоны персон (`persona/`) и данные
агентов хранятся **вне репозитория** (на сервере, в `~/.openclaw/`). Состав и форматы —
см. [`docs/configuration.md`](docs/configuration.md).
