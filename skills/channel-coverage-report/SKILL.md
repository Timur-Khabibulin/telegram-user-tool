# Channel Coverage Report

> **DEPRECATED.** Скилл выведен из эксплуатации, использовать не нужно.

Скилл формирует CSV-файл со всеми каналами платформы, отсортированными по убыванию
среднего охвата, и отправляет его в Saved Messages агента agent1.

---

## Шаг 1 — Вызвать инструмент

```
tg_channel_coverage_report()
```

Инструмент собирает каналы из per-agent БД всех агентов, читает кэшированный
`avg_views`, строит CSV и отправляет файл в Saved Messages.

---

## Шаг 2 — Сообщить оператору итог

По завершении сообщить:

- Сколько каналов попало в отчёт (`channelCount`)
- Сколько агентов охвачено (`agentCount`)
- Что файл отправлен в Saved Messages агента agent1

Пример: «Отчёт отправлен в Saved Messages agent1: 243 канала по 3 агентам.»
