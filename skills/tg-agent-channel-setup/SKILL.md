# tg-agent-channel-setup — создание публичного канала для готовых агентов

Отдельный от регистрации шаг. Для списка уже зарегистрированных агентов
подключается через их собственную сессию, создаёт публичный канал персоны и
закрепляет его в профиле. Персону и username берёт из `tg-account.json` каждого
агента — переуказывать не нужно.

Место в потоке:

```
1. tg-agent-autoregistration (createPublicChannel=false)  — рега пачки без канала
2. tg-agent-channel-setup                                  — этот скилл: каналы
3. private-invite-links                                    — приватные ссылки в закреп-пост
```

---

## Шаг 1 — Собрать список агентов

Спросить у оператора **agentIds** — список идентификаторов уже зарегистрированных
агентов, которым нужно создать публичный канал (например `agent40, agent41, agent42`).

---

## Шаг 2 — Запустить

```
tg_agent_channel_setup(
  agentIds: <список agentId>
)
```

Инструмент по каждому агенту: подключается через его сессию, читает персону/username
из `tg-account.json`, и — если у агента ещё **нет** personal-канала — создаёт
публичный канал персоны (title, `@…_ch`, аватар, пост) и закрепляет его в профиле.

Идёт последовательно, ошибка одного агента не останавливает остальных.

---

## Шаг 3 — Сообщить итог

По результату вывести статус каждого агента:
- `done` — публичный канал создан и закреплён
- `skipped` — у агента уже есть personal-канал (повторный прогон безопасен, дубль не создаётся)
- `failed` — ошибка (текст — в отчёте: нет username/персоны, ошибка Telegram API и т.п.)

Приватные инвайт-ссылки этот скилл не создаёт — для них отдельно запусти
`private-invite-links` (третьим шагом, после того как каналы созданы).
