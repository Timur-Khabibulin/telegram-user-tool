# Channel Cleanup — Чистка слабых каналов

> **DEPRECATED.** Скилл выведен из эксплуатации, использовать не нужно.

Скилл собирает параметры у оператора и запускает чистку одним инструментом.

---

## Шаг 1 — Собрать параметры

При вызове спросить у оператора:

> Для чистки каналов укажи:
>
> • **agents** — список агентов (например `agent1`, `agent2`)
>
> • **minSubsCount** — чистить каналы с подписчиками меньше N (опционально)
>
> • **minAvgViews** — чистить каналы со средним охватом меньше N (опционально)
>
> Хотя бы один из параметров `minSubsCount` / `minAvgViews` обязателен.

Зафиксировать `agents`, `minSubsCount`, `minAvgViews`. Если не хватает данных — спросить только недостающее.

---

## Шаг 2 — Запустить чистку

```
tg_channel_cleanup(
  agents:       <список агентов>,
  minSubsCount: <порог подписчиков, если задан>,
  minAvgViews:  <порог охвата, если задан>
)
```

Инструмент выходит из каналов-кандидатов и удаляет все рабочие данные по ним. По завершении каждого агента отправляет отчёт в Saved Messages агента.

---

## Шаг 3 — Сообщить итог

По результату вывести оператору итог по каждому агенту:
- сколько каналов очищено (`cleaned`)
- сколько ошибок выхода (`leaveFailed`)
