# Funnel Report — воронка по требованию

Этот скилл собирает и показывает воронку по **всем** агентам за **текущий день
UTC+5** (срез «на сейчас»). Метрики берутся свежими через MTProto аккаунтов
агентов и из их БД (`tg-replies.db`, `tg-channels.db`); дельты считаются
относительно последнего сохранённого снапшота.

> Авторитетный дневной срез за **завершившийся** день пишется и уходит в Saved
> Messages agent1 по systemd-таймеру (`tg-funnel-tracker.timer`). Этот скилл — для
> запроса **на сейчас по требованию** и постоянных снапшотов **не пишет**.

---

## Шаг 1 — Построить отчёт

Вызвать инструмент без параметров:

```
tg_funnel_report()
```

Он обходит всех агентов (`listAgentIds()`), по каждому собирает:
- ответы в группах и личные сообщения за день;
- просмотры поста и число подписчиков публичного канала (из профиля аккаунта);
- по agent1 — число заявок на вступление в приватный канал;

считает дельты относительно последнего среза и возвращает `{ text, result }`:

- `text` — готовый человекочитаемый отчёт-таблица (агент → Группы, Личные,
  Просмотры поста `+Δ (abs)`, Подписчики канала `+Δ (abs)`), строка «Итого» и
  строка «Заявки в приватный канал: +Δ (N)». Внизу — пометки о пропусках
  (агент без канала в профиле, недоступные заявки, ошибки);
- `result` — структура с полями по агентам и заявкам, если нужно отфильтровать
  или пересчитать что-то сверх текста.

## Шаг 2 — Показать пользователю

Вывести поле `text` **дословно, как есть** — оно уже содержит готовую таблицу в
код-блоке (```), выровненную под Telegram. **Нельзя** переформатировать его,
превращать в markdown-таблицу с `|`, пересчитывать ширины или выравнивать заново —
это сломает вид. Просто отдать `text` одним сообщением без изменений.

Если просили срез (конкретный агент, только заявки и т.п.) — тогда отфильтровать
по `result` и ответить текстом, но обычный полный отчёт показывается строго как `text`.

---

## Ограничения и заметки

- Окно — **текущий день UTC+5** до момента вызова. Дельта = прирост с последнего
  сохранённого снапшота.
- Запуск по требованию **не пишет** дневной снапшот — не влияет на таймерный ряд
  и не считается дублем для автосводки.
- Сбор подключается к аккаунту каждого агента (через его прокси) — ответ может
  занять заметное время при большом числе агентов.
- Если у агента не задан канал в профиле или у agent1 нет прав на заявки —
  соответствующие значения помечаются в отчёте, прогон не падает.
