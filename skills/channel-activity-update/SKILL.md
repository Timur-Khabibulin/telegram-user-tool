# Channel Activity Update

> **DEPRECATED.** Скилл выведен из эксплуатации, использовать не нужно.

Запускает пересчёт метрик канала (`avg_views`, `subs_count`, `active_writers_p50`,
`active_writers_p90`) для явно перечисленных агентов, в обход TTL — пересчитываются
ВСЕ каналы каждого агента, а не только просроченные.

Плановый пересчёт (только просроченные по TTL каналы, все агенты) и так идёт
каждый день в 03:00 UTC (`tg-channel-activity-update.timer`) — этот скилл нужен
только для точечного ручного запуска.

---

## Шаг 1 — Вызвать инструмент

```
tg_channel_activity_update({ agentIds: ["agent10", "agent27"], limit: 5 })
```

- `agentIds` — обязателен, список конкретных агентов из запроса оператора.
- `limit` — необязателен: сколько каналов взять у КАЖДОГО перечисленного
  агента. Полезно для точечной проверки перед полным прогоном на агента с
  сотнями каналов.

## Что происходит на самом деле

Инструмент запускает `tg-channel-activity-update-manual@<agentIds>[.limitN].service`
через `systemctl start` и **не ждёт завершения** — прогон читает полную историю
чата за 30 дней на каждый канал и может идти от минут до часов. Инструмент
возвращает только факт успешного запуска юнита:

```json
{ "instance": "agent10-agent27.limit5", "systemctl": { "ok": true, "cmd": "systemctl start ..." } }
```

`systemctl.ok = false` — юнит не запустился (например, невалидное имя юнита или
systemd недоступен) — это ошибка запуска, а не ошибка самого пересчёта.

## Шаг 2 — Сообщить оператору итог

Сообщить, что пересчёт запущен в фоне, и что результат появится не сразу:

Пример: «Пересчёт активности и охвата для agent10, agent27 запущен в фоне —
займёт от нескольких минут до пары часов, значения появятся в отчётах
постепенно, дожидаться прямо сейчас не нужно.»

Если `systemctl.ok = false` — сообщить об ошибке запуска дословно из
`systemctl.error`, не пытаться повторить автоматически.

## Как проверить результат позже (для оператора, не для скилла)

Через `vps`-доступ:

```bash
ssh -i ~/.ssh/vps_key root@<VPS_HOST> "journalctl -u 'tg-channel-activity-update-manual@*' -S -1h"
```
