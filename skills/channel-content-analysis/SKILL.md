# Channel Content Analysis — анализ контента топ-каналов агентов

> **DEPRECATED.** Скилл выведен из эксплуатации, использовать не нужно.

Операторский скилл: по заданным агентам собирает посты их самых крупных каналов,
считает вовлечённость и тему каждого поста, выгружает единый CSV-отчёт. Цель — понять,
о чём и насколько успешно пишут топ-каналы, и взять идеи для контента основного агента.

---

## Шаг 1 — Собрать параметры

При вызове скилла **одним сообщением** запроси у оператора, что нужно:

> Чтобы проанализировать контент топ-каналов, мне нужно:
>
> • **агенты** — у каких агентов брать каналы (анализ идёт по каждому отдельно).
>
> • **n** — сколько последних постов взять с каждого канала.
>
> • **m** — процент самых крупных каналов у каждого агента (например, 30 — берём верхние
>   30% по числу подписчиков). От 0 до 100.
>
> *(необязательно)* админ-агент — владелец папки отчётов и получатель CSV в Saved
> Messages; по умолчанию админ-агент платформы.

Зафиксируй `agents`, `n`, `m`. Если что-то не указано — переспроси только недостающее
(все три обязательны: `agents` непуст, `n > 0`, `m` в диапазоне (0, 100]).

Если оператор спросит про вовлечённость — поясни: считаем **ERR = пересылки (репосты) /
просмотры × 100%**. Это нормированный процент, сравнимый между каналами любого размера;
репосты — сигнал «контентом делятся». Свежие посты могут иметь заниженный ERR
(охват ещё не накопился) — поэтому в отчёте есть колонка возраста поста.

## Шаг 2 — Запустить анализ

```
tg_channel_content_analysis(
  agents: <список агентов>,
  n:      <постов с канала>,
  m:      <процент крупнейших каналов>
  [, adminAgentId: <агент>]
)
```

Прогон идёт последовательно по агентам на их сессиях. Анализируются только
broadcast-каналы (группы и обсуждения отбрасываются). Сбой на отдельном канале или
агенте не валит прогон — пропускается с записью причины.

## Шаг 3 — Показать отчёт

Выведи оператору поле `report` из ответа: сколько агентов обработано, сколько каналов
проанализировано и постов попало в отчёт, сколько пропущено и почему. Полная таблица —
в CSV-файле, который ушёл в Saved Messages админ-агента и сохранён на сервере
(`reports/channel-analysis-<UTC-timestamp>.csv`). Колонки CSV: `agent, channel,
channel_size, topic, summary, ERR, views, reactions, comments, forwards, age_days, link`.
Сообщение-отчёт также содержит пояснение формулы ERR и колонки `age_days`.
