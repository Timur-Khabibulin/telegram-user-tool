# Daily Summary — дневная сводка прогонов

Этот скилл показывает агрегированную сводку прогонов **всех** агентов за **текущий
день по UTC+5** (от полуночи до текущего момента). Данные берутся из таблиц `runs`
каждого агента — по строке на каждый прогон скилла (статус, длительность, число
LLM-запросов, ошибка).

> Автоматическая сводка за **завершившийся** день уходит в Saved Messages
> админ-аккаунта по systemd-таймеру (`tg-daily-summary.timer`). Этот скилл — для
> запроса **за сегодня по требованию**.

---

## Шаг 1 — Построить сводку

Вызвать инструмент без параметров:

```
tg_daily_summary()
```

Он обходит все per-agent БД, агрегирует прогоны за текущий день UTC+5 и возвращает
`{ summary, text }`, где:

- `text` — готовый человекочитаемый отчёт: шапка с общим итогом (прогонов, успехов,
  ошибок, LLM-запросов, время) + **список ошибок** (агент · скилл · текст ошибки —
  сколько раз). Список агентов по скиллам в тексте не печатается;
- `summary` — структура с полями `total`, `errors` (сгруппированные ошибки) и
  `perAgent[agentId][type]` (`runs`, `success`, `error`, `llmCalls`, `durationMs`) —
  на случай, если нужно посчитать/отфильтровать что-то сверх текста.

## Шаг 2 — Показать пользователю

Вывести пользователю поле `text` как есть. Если просили срез (например только
ошибки или конкретный агент) — отфильтровать/пересказать по `summary`.

Если за сегодня прогонов не было, `text` содержит «Нет прогонов за период» —
так и сообщить.

---

## Ограничения и заметки

- Окно — **сегодня по UTC+5** до момента вызова. За другой день/диапазон этот
  инструмент не считает (автосводка по таймеру покрывает завершившийся день).
- Сводка только читает БД агентов (readonly-семантика) и не влияет на их работу.
